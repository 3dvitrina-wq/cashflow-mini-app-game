## First-Card Deadlock Fix

Request:

- First card got stuck in offline play:
  buy / pass looked available, but the round never resolved.

Actions:

- Reproduced the bug on the deterministic first offline card `opp-storage`.
- Verified the root cause:
  - bot policy treated `partnership.invite` as affordable because it only looked at `cash.delta`;
  - the engine correctly rejected that intent because co-invest has a real upfront contribution;
  - offline intent windows then waited forever because bot slots stayed empty.
- Patched `packages/game-engine/src/bot.ts` to use `canAffordChoice(...)`
  instead of the old cash-only heuristic.
- Added a store-side safety net in `apps/web/src/store/index.ts`:
  if an offline auto-filled intent still fails to queue, that player now falls back to `pass`
  instead of deadlocking the whole month.
- Added a regression test in
  `packages/game-engine/src/__tests__/economy-wiring.test.ts`
  proving low-cash bots pass on unaffordable co-invest options and the intent window completes.

Verification:

- `npx vitest run packages/game-engine/src/__tests__/economy-wiring.test.ts`
- `npm run typecheck`

Decisions:

- Simultaneous rounds must fail soft offline:
  a bad bot intent should degrade to `pass`, not freeze the match.
