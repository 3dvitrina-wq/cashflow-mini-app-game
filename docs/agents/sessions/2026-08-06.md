# Session 2026-08-06 — Telegram private-hand images

## Symptom

On iPhone Telegram over 3G, the BASIC private hand rendered current copy and
controls but the art column of all three cards stayed black. A fresh production
browser loaded the same art, isolating the defect to Telegram cache/loading
behavior rather than missing card definitions or a failed game bootstrap.

## Repair

- Replaced inline CSS background images in `PersonalCardPicker` with eager
  `<img>` elements so the WebView prioritizes visible card media.
- Added an immediate category glyph/gradient behind every image. Failed or slow
  media no longer produces an unexplained black rectangle.
- Added image error handling that reveals the fallback instead of a broken-image
  artifact.
- Changed the real `@ClubDyorGame_bot` menu URL through Telegram Bot API from the
  unversioned Pages root to
  `https://cashflow-mini-app-game.pages.dev/?release=20260806b`, forcing a fresh
  Mini App document after deployment.
