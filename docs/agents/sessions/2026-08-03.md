# Session 2026-08-03 — one notice language and learn by doing

## Product decision

The interface now distinguishes three meanings instead of styling every message
as an unrelated popup:

- **Persistent game truth** stays at its source: `ЛИЧНАЯ КАРТА · ТОЛЬКО ВАМ`
  is part of every BASIC card and `РЫНОК · ВСЕМ` remains on the shared market.
- **Transient feedback** (success, warning, error and host remark) uses one
  centered notice lane with one semantic icon system and one dismissal pattern.
- **Actionable multiplayer requests** such as deal acceptance remain interactive
  banners/sheets; they are not short-lived notifications.

This removes the second floating host bubble and the separate reconnect banner.
The global notice host is mounted once for the whole app, so lobby, shop and
secondary screens no longer depend on a screen-local toast container.

## First-run learning

- Step 1 now states before anything else: `Эта карта принадлежит только вам`.
  It also explains that the other players have their own cards.
- The flow is ten short steps. The learner taps a real available decision, then
  opens the real `?` calculation for cash, passive income, expenses and cashflow.
- The player-rail step opens the actual profile and sends an actual reaction.
- The tutorial keeps the local/server clock paused and suppresses decorative host
  remarks. The final action restores focus to `Подтвердить`, then the clock runs.
- BASIC and PRO retain separate scope copy: private ownership is never taught in
  the shared-card PRO mode.

## Process observations for Studio

- Route UI messages by **intent**, not by the file or subsystem that emitted
  them. Persistent truth, transient feedback and actionable requests need three
  explicit contracts; a generic “banner” category recreates the original chaos.
- A single global renderer prevents invisible notifications on secondary screens
  and removes duplicate mounts. Dedupe keys are essential for long-lived network
  state and host cooldowns.
- Suppress nonessential narration while onboarding is active. Teaching and host
  personality competing for the same attention is not dynamism.
- For repeat browser verification, one initial accessibility snapshot plus scoped
  role counts, timer values and geometry probes consumed far less context than
  repeated full-page dumps while still proving the real interactions.

## Telegram-safe windows and game feel follow-up

- Audited bank, market, labor, pets, events, daily reward, settings, cashflow,
  own profile and player profile at 402×874. The own-profile sheet was the direct
  Telegram collision: top about 35px and Back about 70px. It now uses the shared
  86dvh contract: top about 122px and Back about 157px.
- Bottom sheets now have one visible 44px Back control, heading hierarchy,
  dialog semantics, Escape dismissal and shared safe-bottom padding. Cashflow
  moved from its bespoke modal into the same component. A bubbling cashflow tap
  that also opened the profile was found and fixed.
- Daily reward now has an explicit close and a separate `lastDailyClaimDate`, so
  reopening cannot duplicate currency. Fake rare-card/pet-food rewards were
  replaced by persisted coins.
- Settings now exposes only truthful controls. Master volume, music, action
  sounds, haptics, host and language work; unwired match sliders, links and dead
  destructive buttons are hidden until authoritative actions exist.
- Original procedural Web Audio now provides button clicks, event stingers and
  a quiet ambient sequence without third-party audio rights.
- Bot reactions moved from a rare last-seven-seconds lottery to one contextual
  response after the card reveal, with the rare late reaction retained.
- Generated emotion art was present but not loaded: a `.webp` glob was parsed by
  a `.png` regex. Fixing it restores visible stress/crisis/recovery states.
- Labor no longer exposes a fake auction or false staff bonuses. Market risk
  labels were removed until risk is mechanical; three canonical $1K–$3K assets
  make the early market a real choice. Pet synergies and multi-pet ownership were
  removed until the engine supports them.
- Independent critic result: 12/24 overall, Experience Design 1/4. Full evidence
  and remaining P0/P1 work live in `.planning/UI-REVIEW.md`; the durable product
  rules live in `docs/second_brain/10_game_design/UI_TRUTH_AND_MOMENTUM_AUDIT.md`.

## Final publication pass

- Repeat play now has an honest primary route: `Быстрый матч` starts BASIC with
  five bots and 15 rounds; the people/room route is secondary and explicit.
- Fabricated lobby counters (online players, likes, views and minimum earned
  achievements) were removed. The lobby shows only actual XP, actual unlocked
  achievements and real match parameters.
- Telegram reserves a 104px top control strip even when the client does not
  report fullscreen. The first tutorial tooltip starts at about 112px in the
  402×874 test and no longer competes with Telegram Close/ellipsis.
- The first tutorial step was shortened to a single job: establish private card
  ownership. Timer verification remained `00:90 → 00:90` while it was open.
- Labor/pet entrance animation was shortened to 280/240ms: motion communicates
  arrival without delaying access to the actual decision.
