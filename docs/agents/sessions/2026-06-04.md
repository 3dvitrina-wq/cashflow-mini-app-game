  - pets
  - deposits
  - loan/deal/interest-window sync
- Added deposits to `BankScreen` so the safe strategy is actually playable in UI.
- Patched multiplayer/server flow so off-turn side-actions no longer force a month advance and no longer hard-fail solely because the sender is not the active player.
- Patched the table UI and onboarding copy to make turn ownership / phase state more explicit.
- Replaced the fake event-log generator with a projection from the real `engineMatch.eventLog`.
- Reworked recap selection to use the local player id and real event history instead of purely random failure/decision text.
