# Session 2026-07-30

## Goal

Prepare a free local multiplayer playtest on one computer so six independent player
profiles can exercise the real server without requiring six people or public deployment.

## Decisions

- Current priority is fun and stability on localhost.
- Telegram HMAC, Postgres/Redis, paid hosting and production deployment are deferred.
- Network Lab is an isolated test node before integration; it does not own engine or
  room authority.
- Six profiles use six real WebSocket connections and distinct player ids.
- Server room acknowledgement is required before a profile is shown as connected.
- Diagnostic hashes compare only current joined clients; missing or stale snapshots are
  shown as WAIT/STALE rather than false divergence.

## Delivered

- Added `tools/network-lab/index.html`, `app.js`, `styles.css`, `smoke.mjs` and `README.md`.
- Added shared/individual starts, per-profile choices and Auto, global Auto/Pause,

- Added the Studio V2 node `module-network-lab`, grants for Multiplayer Builder and QA
