# Workflow

## Daily Loop

1. Run `python3 tools/agent_autosync.py`.
2. Read `docs/agents/AGENT_WIKILINKS.md`.
3. Read `docs/agents/ACTIVE_TASK.md`.
4. Make focused changes.
5. Update `ACTIVE_TASK.md` and today's session log.
6. Run `python3 tools/agent_autosync.py` before final response.

## Truth Sources

- Code behavior: git + source files.
- Product intent: `.planning/PROJECT.md`.
- Requirements: `.planning/REQUIREMENTS.md`.
- Phase plan: `.planning/ROADMAP.md` and `.planning/phases/`.
- Game design memory: `docs/second_brain/`.
- Session decisions: `docs/agents/sessions/`.
