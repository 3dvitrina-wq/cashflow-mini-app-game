## 1. Что заимствуем — выжимка аналогов

### Cashflow 101/202 (Kiyosaki)
**Берём:**
- Financial Dashboard как основной экран портфеля (активы/пассивы/доход/расход)
- Два трека прогрессии: Rat Race (выживание) → Fast Track (свобода)
- Карточки событий: Investment / Doodad / Market
- Ручное ощущение "я управляю своим отчётом"

**Не берём:**
- Кубик и физическое поле (не наш жанр)
- 3-4 часа на партию (у нас 25-45 мин)

### Monopoly
**Берём:**
- Аукционы: если игрок пропускает актив — все торгуются
- Прямой PvP-конфликт через ренту/сделки
- Социальная составляющая: переговоры как ядро

**Не берём:**
- Линейное поле с клетками
- Elimination (игрок выбывает и скучает)

### Acquire
**Берём:**
- Слияния бизнесов: объединяешь два актива → бонус
- Скрытая информация: не видишь портфели соперников (по умолчанию)
- Тайминг инвестиций: когда входить, когда выходить

### Marvel Snap
**Берём:**
- Свайп-карточки (вверх = разыграть, вниз = сбросить)
- Face-down cards для саспенса
- Snap-механика: удвоение ставки в сделке + блеф
- 3-6 минут на партию (для quick mode)

**Не берём:**
- Колодостроение (у нас общая колода событий)

### Hearthstone
**Берём:**
- Тактильный card UX: "шлёпок" на стол, покачивание в руке
- Эмоты вместо чата (наши реакции-стикеры)
- Long-press = полноэкранный просмотр карты
- Интерактивные элементы пока ждёшь ход

### Game of Life
**Берём:**
- Life simulation: карьера, семья, питомцы — narrative
- Визуальная прогрессия: машинка с фишками-человечками
- Развилки: безопасный путь vs. рискованный

### AdVenture Capitalist
**Берём:**
- Офлайн-прогресс: пассивный доход пока игрок оффлайн
- Prestige-система: сброс = перманентные бонусы
- Лимитированные ивенты: еженедельные тематические рынки

### Hamster Kombat / Telegram games
**Берём:**
- HapticFeedback на каждом взаимодействии
- shareMessage / shareToStory для виральности
- Emoji Status как бейджи достижений
- CloudStorage для синхронизации прогресса

## 2. UX/UI решения — как впихнуть невпихуемое

### Навигация: 3 таба

```
┌─────────────────────────────────┐
│  [Стол]  [Портфель]  [Магазин] │
└─────────────────────────────────┘
```

- **Стол** — основной игровой экран (текущий MainTurnTable)
- **Портфель** — Financial Dashboard + активы + рынок труда + питомцы
- **Магазин** — скины + одежда + питомцы + character editor

### Жесты

| Жест | Где | Действие |
|---|---|---|
| Свайп ↑ по карте | Стол | Взять/принять карту |
| Свайп ↓ по карте | Стол | Пропустить/отклонить |
| Свайп ←/→ | Стол | Перелистнуть карты в руке |
| Long press на карте | Стол | Полный просмотр + тултипы |
| Тап на аватар | Стол | Profile popup → предложить сделку |
| Свайп к игроку | Стол | Отправить deal-предложение |
| Pull down | Портфель | Обновить рыночные данные |
| Double tap | Любой | Быстрая реакция (стикер) |
| Свайп ↑ bottom sheet | Любой | Открыть панель (питомцы, рынок труда) |
| Свайп ↓ bottom sheet | Любой | Закрыть панель |

### Bottom Sheets вместо отдельных экранов

Всё вторичное — в bottom sheets:
- Рынок труда
- Питомцы
- Shop (скины)
- Character editor
- Event log
- Настройки

**Почему:** игрок не теряет контекст игры, быстро возвращается к столу.

### Floating Action Button (FAB)

```
┌─────────────────────────────────┐
│                                  │
│                                  │
│                          [+]    │
└─────────────────────────────────┘
```

"+" в правом нижнем углу → радиальное меню:
- 🧑‍💼 Рынок труда
- 🐾 Питомцы
- 🤝 Предложить сделку
- 📊 Фьючерсы

### Toast-уведомления

Всплывающие подсказки сверху (не модалки):
- "Рынок изменился!"
- "Антон предлагает сделку"
- "Питомец снижает стресс -1"
- "Новая карта в руке"

### Haptic Feedback

- **Light** — тап по кнопке, свайп карты
- **Medium** — покупка, принятие сделки
- **Heavy** — кризис, банкротство, крупная потеря
- **Success** — выигрыш, достижение

### Микро-анимации

- Цифры cash "тикают" при изменении (как счётчик)
- Stress-бар пульсирует при >7
- Trust-бар мерцает при сделке с низким trust
- Карта "шлёпается" на стол при розыгрыше
- Аватар "кивает" при принятии, "мотает" при отказе

## 7. Критерии успеха

После всех 6 волн:
- ✅ Игрок понимает правила за 5 минут (onboarding)
- ✅ Видит свой финансовый отчёт (dashboard)
- ✅ Может свайпать карты (core loop)
- ✅ Кастомизирует персонажа (shop)
- ✅ Нанимает работников и питомцев (глубина)
- ✅ Предлагает сделки другим (социалка)
- ✅ Возвращается за daily bonus (retention)

**Метрика:** игрок проходит 3+ матча без объяснения правил.
