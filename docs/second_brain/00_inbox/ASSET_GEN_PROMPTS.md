# Промты для генерации SVG/ассетов

**Дата:** 2026-05-29  
**Для:** Midjourney / DALL-E / Stable Diffusion  
**Стиль:** 2.5D toy-comic, matte clay/plastic текстуры, bold силуэты, dark UI

---

## Общие требования к стилю

**Палитра (из текущего UI):**
- Canvas: `#0B0D11` (почти чёрный)
- Text: `#F5F4ED` (тёплый белый)
- Gold/Cash: `#F5C524`
- Green/Profit: `#28C76F`
- Red/Debt: `#E84B2A`
- Purple/Host: `#7B5BD7`
- Cyan/Epoch: `#5BD7E0`

**Стиль:**
- Flat design с лёгкими градиентами
- Минимум деталей, максимум читаемости
- Скруглённые углы (12-20px)
- Тени минимальные, только для глубины
- Эмодзи-стиль для персонажей (дружелюбный, не реалистичный)

**Формат:**
- SVG для иконок и простых иллюстраций
- PNG 512x512 для сложных иллюстраций
- Прозрачный фон где возможно

## Инструкции по генерации

1. **Midjourney:** добавь `--style raw --ar 1:1` для квадратных изображений
2. **DALL-E:** используй промты как есть
3. **Stable Diffusion:** добавь negative prompt: `realistic, photo, 3d render, blurry, low quality`

**Post-processing:**
- Убрать фон (remove.bg или Photoshop)
- Конвертировать в SVG где возможно (vectorization)
- Оптимизировать PNG (TinyPNG)
- Проверить читаемость на dark background #0B0D11
