# Character Visual Style Prompt

## Purpose

Define a visual direction for DYOR characters that is distinctive, Telegram-native, funny, scalable, and not a clone of Monopoly, Mario, generic 3D mobile avatars, or corporate fintech mascots.

## Core Style Direction

DYOR should use **satirical editorial toy-comic characters**:

- simplified 3D-like forms with flat graphic shading;
- thick silhouette, readable at mobile size;
- expressive faces and posture;
- slightly absurd props;
- clean shapes, not over-detailed realism;
- comic-panel attitude;
- sticker/GIF friendly;
- UI-friendly on dark and light backgrounds.

Think:

- editorial cartoon meets collectible vinyl toy;
- financial meme sticker pack;
- board-game token with emotional damage;
- modern mobile avatar, but sharper and more satirical.

Avoid:

- Monopoly gentleman clone;
- Mario-like mascot proportions;
- generic Roblox/Bitmoji/Apple Memoji look;
- realistic corporate illustration;
- beige fintech minimalism;
- crypto bro ape look;
- over-rendered Pixar clone;
- cheap casino style.

## Visual DNA

### Shapes

- big readable head and hands;
- compact body;
- strong posture line;
- props tell financial state;
- shoes/briefcase/phone/receipt stack as recurring motif.

### Face

- eyes and brows carry emotion;
- mouth can be minimal;
- stress lines, sweat, deadpan, suspicious smile;
- expression must work as sticker.

### Materials

- matte clay/plastic surfaces;
- flat-color clothing;
- subtle grain/noise;
- simple rim shadow;
- no glossy casino gold overload.

### Color

Palette should support comedy and status:

- stress red;
- debt purple/bruise;
- safe green;
- bureaucratic gray;
- crypto neon accent;
- tax-office yellow paper;
- cardboard brown only for crisis states, not whole UI.

Avoid one-note palette.

## Character States

Each player avatar needs state variants:

- stable/confident;
- tired/overworked;
- overleveraged;
- cardboard-box crisis;
- tax panic;
- futures liquidation;
- legal battle;
- passive income calm;
- digital nomad survival;
- comeback mode.

States should change silhouette/props, not only facial expression.

Examples:

- overleveraged: phone in one hand, three red notifications, tie loose.
- cardboard-box crisis: box armor, tiny umbrella, rent note.
- tax panic: paper avalanche, stamp mark on forehead.
- passive income calm: slippers, tea, tiny rental keys.
- futures liquidation: candle chart arrow stuck through hat.

## Host Characters

AI host personalities should be visually distinct:

- Judge: clean dark robe, tiny calculator gavel.
- Joker: chaotic tie, receipt confetti.
- Provocateur: sharp grin, red pen, spotlight.
- Coach: clipboard, warm posture.
- Broker: too shiny suit, suspicious thumbs-up.
- Tax Inspector: calm face, giant stamp.

Host must never look like real public figures.

## Card Art Direction

Cards can use the same simplified toy-comic language:

- big prop;
- one emotional character;
- short readable title;
- strong icon tag;
- one absurd detail.

Card types:

- Opportunity: bright, tempting, slight danger.
- Crisis: dramatic, funny, not horror.
- Protection: boring but heroic.
- Social Deal: two characters and contract prop.
- Macro Event: giant policy/weather symbol.
- Futures: aggressive neon chart, but satirical.

## Animation Direction

Use short loops:

- idle bounce;
- stress shake;
- receipt rain;
- chart slap;
- tax stamp;
- cardboard box wiggle;
- passive-income tea sip;
- resignation mic drop;
- lawyer contract snap.

Keep loops under 2 seconds for Telegram feel.

## Image Generation Prompt Template

Use this for character concept exploration:

```text
Create a distinctive character design for "DYOR", a satirical Telegram financial strategy game. Style: simplified 3D toy-comic avatar with flat graphic shading, expressive face, strong silhouette, matte clay/plastic texture, sticker-friendly, mobile-game readable, dark UI compatible. The character should feel like an editorial cartoon about modern money stress, not Monopoly, not Mario, not Memoji, not generic crypto art.

Character state: [stable / overworked / cardboard-box crisis / tax panic / futures liquidation / passive-income calm / digital nomad survival].
Props: [receipts, phone notifications, tiny contract, tax stamp, cardboard box, chart candle, rental keys, laptop].
Mood: funny, ironic, emotionally readable, slightly absurd but grounded.
Composition: centered full-body avatar, clean background, bold readable shapes, no text, no logos, no real brands, no real politicians.
Color: balanced palette with accent color [accent], avoid single-color monotony.
Output: concept art suitable for sticker pack, avatar state, and animated loop reference.
```

## Negative Prompt

```text
Avoid Monopoly mascot, Mario style, Disney/Pixar clone, Memoji, Roblox, anime waifu, casino slot art, realistic politician, real celebrity, luxury crypto bro, bored corporate SaaS illustration, excessive gradients, tiny details, unreadable props, real logos, copyrighted characters.
```

## Recommendation

Use 2.5D toy-comic as the main style, not pure flat comic and not full realistic 3D.

Why:

- works as stickers/GIFs;
- can animate cheaply;
- distinctive enough for branding;
- readable on phones;
- supports emotional state changes;
- less generic than fintech flat art;
- less expensive than high-end 3D video.
