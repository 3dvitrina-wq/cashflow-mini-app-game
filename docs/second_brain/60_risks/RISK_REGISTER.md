# Risk Register

| Risk | Severity | Mitigation |
|------|----------|------------|
| IP similarity to Cashflow | High | Use original name, art, cards, board, rules, language |
| Financial advice perception | High | Fictional markets, disclaimers, educational framing |
| AI host hallucination | High | AI never resolves rules; deterministic fallback |
| Deal chat chaos | Medium | Structured offers and timers |
| Player disconnect stalls match | High | Bot replacement after timeout |
| Pay-to-win temptation | High | Monetize cosmetics/social/tournaments only |
| Video/audio cost | Medium | Feature flag, post-MVP only |
| Game too complex | High | Tutorial sprint, progressive mechanics |
| Risky mechanics glamorize leverage | High | Reward survival and risk-adjusted performance |
| Telegram platform changes | Medium | Keep web app portable, isolate Telegram adapter |
